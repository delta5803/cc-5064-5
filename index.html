如何启动 / 操作说明

启动界面：在 /workspace 运行 npm start（等价 node serve.mjs），浏览器打开终端打印的 http://localhost:5180/。也可用 python3 -m http.server 5180 后访问。必须经 http 打开（ES 模块限制）。

无界面校验：npm run verify 运行同一分簇内核的漏光/参考图一致性、预算状态机与拖动防混版本测试，并在 artifacts/ 输出对比 PNG。

  • 拖动彩色灯手柄即可实时拖灯预览；内核每次生成不可变完整帧并整体上传。
  • “复现”会关闭整排街灯并把横街巨灯拉到近裁面附近，观察某簇原始候选超过容量后如何被全局表/溢出表完整容纳。
  • 把策略切到“固定容量”或调小预算，可看到：不截断、不暗区，而是保留上个完整帧并以斜纹显示“待算区域”。
  • 点画面亮斑取簇，用每盏灯的“关/独亮”核对亮斑来源；运行参考对比查看 PSNR、漏光数与计算次数/加速比。
